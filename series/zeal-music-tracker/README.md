# Zeal Music Tracker

Watch on [YouTube: @zoul0813](https://www.youtube.com/@zoul0813).

Build **Zeal Quest** in [Zeal Music Tracker](https://github.com/zoul0813/zeal-music-tracker).
Download the starting file for the episode you are following. In Zeal Native,
put it in your host filesystem folder so it appears on `H:`. On hardware,
copy it to a mounted drive. Start the tracker from that directory, then press
`L` and enter the file name.

Save your own version as `myquest.zmt`. The finished checkpoint for each
lesson lets you check your work or pick up from the next lesson.
