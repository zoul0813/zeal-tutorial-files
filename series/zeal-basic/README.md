# Zeal BBC BASIC

Watch on [YouTube: @zoul0813](https://www.youtube.com/@zoul0813).

Build **Silent Beacon** in [Zeal BBC BASIC](https://github.com/Zeal8bit/Zeal-BBC-Basic).
The `.bbc` files are saved BASIC programs. Copy them to a drive visible
to Zeal OS, then use BASIC's `LOAD` command with the file name from the video.

`beacon.bbc` is the complete game. The numbered files let you pick up at a
specific lesson. Keep your working program under its own name so you can
return to the supplied checkpoint.
