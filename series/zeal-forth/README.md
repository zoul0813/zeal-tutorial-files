# Zeal Forth

Watch on [YouTube: @zoul0813](https://www.youtube.com/@zoul0813).

Build **Lantern Keep** one lesson at a time. Each numbered folder contains
the completed source (`keep.fs`) and its matching checks (`check.fs`).

Use [Zeal Forth](https://github.com/zoul0813/zeal-forth) and load the
[course version of forth.fs](https://github.com/zoul0813/zeal-forth/blob/3871f9b1356aaaceac7a78d38a8e12e71ef869eb/forth.fs)
before loading the game's source into a fresh interpreter. To pick up where
the previous episode ended, start with that episode's `keep.fs`. To check
your work, use the `check.fs` from the episode you are following.
